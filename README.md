# VS Code Plugin: Line Sorter

**Автор:** Ярослав, группа М3117
**Среда разработки:** Visual Studio Code

## Описание
Плагин расширяет базовый функционал текстового редактора VS Code, добавляя инструмент для  сортировки выделенных строк. 

## Возможности
- Чтение выделенного пользователем фрагмента текста через расширение вски
- Преобразую текст в массив строк.
- Сортировка массива по алфавиту.
- Перезапись исходника на отсортированный вариант.

## Использование
1. Выделите нужные строки в любом открытом текстовом файле.
2. Нажмите (`Ctrl+Shift+P`).
3. Пропишите `Sort Selected Lines` и нажмите enter.
